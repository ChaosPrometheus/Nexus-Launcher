# Nexus Launcher

Кастомный лаунчер Minecraft на Python с тёмным интерфейсом, профилями и собственной папкой версий.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## Возможности

- Тёмный интерфейс в стиле официального лаунчера
- Профили (установки) с отдельными настройками
- Своя папка данных **NexusData** (версии не смешиваются с `.minecraft`)
- Поддержка уже установленных версий: Vanilla, Forge, Fabric, Quilt, NeoForge
- Каталог релизов Mojang (скачивание прямо из лаунчера)
- Своя папка игры для каждой сборки (сейвы, моды, конфиги)
- Смена ника (оффлайн-режим)
- Настройка JVM-аргументов и пути к Java

## Установка

1. Установите Python 3.10 или новее  
2. Установите зависимости:

```bash
pip install customtkinter minecraft-launcher-lib pillow
```
#
Использование

Откройте вкладку Установки

Нажмите + Новая установка

Укажите название профиля и выберите версию

При необходимости выберите свою папку для сейвов/модов

Сохраните и нажмите ИГРАТЬ

Версии скачиваются в папку лаунчера.
